独立复核修复了三类证据完整性问题：异步分析中的输入变化、旧打印内容残留、`File.text()` 导致 BOM 丢失后的文件指纹差异。另外补齐常见 MCP JSON 中的 npx 未固定版本检查，并对导出 Markdown 的外来语法做转义。

## 实际限制

以上不等于安全扫描效果基准、跨所有浏览器兼容性验证或生产负载测试。规则是启发式文字匹配，用户输入的示例与注释也可能触发。本站没有真实付费客户、收入或使用量的验证数据；发布验证与收入验证分开记录。

隐私声明覆盖应用代码行为，不保证托管平台没有网页访问日志。CLI 只生成静态分析报告，团队验收信息需在浏览器填写。当前不支持保存到云端、旧报告导入或多人同步。

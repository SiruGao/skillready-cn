    先把常见问题说清楚。

    文件会发给模型或服务器吗？

    不会。分析在浏览器中完成，不调用模型 API，不上传所选文件、不使用分析埋点，也不保存到浏览器本地存储。网站托管服务仍会处理普通网页访问请求。

    没有发现高关注项，代表可以直接上线吗？

    不能。静态规则只能发现部分文本线索；工具不会解析全部依赖、运行脚本或验证真实权限。请在隔离环境中测试，并完成人工验收。

    支持哪些 Agent？

    本版本检查遵循 Agent Skills 结构的 SKILL.md、常见 MCP JSON 配置及文本脚本。它不安装技能、不转换客户端配置，也不保证与某个 Agent 的运行兼容性。

    免费版有限制吗？

    当前本地工作台全部免费。为保持浏览器响应，一次最多 100 个文件、每文件 1 MB、合计 5 MB。后续团队服务按具体工作范围单独约定。

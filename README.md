# SkillReady · 技能上岗单

**给 AI 技能一张可交接的中文接入记录。**

**在线使用：[打开 SkillReady](https://sirugao.github.io/skillready-cn/)**

浏览器本地整理 AI Skill 的权限线索、外联域名、凭证名称、文件指纹和人工验收。面向需要交接技能的中文小团队、AI 实施服务商与开发者。

本项目提供静态规则线索与接入记录，**不提供安全认证**。没有发现不意味着技能安全；人工勾选不是工具验证的运行事实。

## 使用

- 浏览器工作台：从本机选择文本文件、文件夹，或直接粘贴内容。
- 查看可定位证据、SHA-256、域名与凭证名称清单。
- 填写用途、数据范围、负责人和验收人，记录每条发现的处理说明。
- 导出 Markdown / JSON 验收包，或打印保存为 PDF。
- 页面刷新后内容清空，请主动导出需要保留的记录。当前版本不导入旧报告、不执行技能、不安装依赖。

所有分析在浏览器或本机 CLI 内完成；不调用模型、不上传用户所选文件，不使用遥测。正常的网站访问仍由托管平台处理。

## 本机运行

需要 Node.js 20 或以上，无 npm 依赖。

```bash
git clone https://github.com/SiruGao/skillready-cn.git
cd skillready-cn
npm start
# 打开 http://127.0.0.1:4173
```

通过 localhost 或 HTTPS 访问，使浏览器支持 SHA-256；不建议直接双击 HTML 文件。

## CLI / CI

```bash
node cli.mjs ./my-skill --json ./review.json --fail-on high
node cli.mjs ./my-skill --allow-domain api.example.com --fail-on medium
node cli.mjs ./my-skill --fail-on none
npm test
```

CLI JSON 是静态分析报告；浏览器导出的 JSON 还包含团队填写的人工验收记录。两者有独立结构，不能视为相同格式。

退出码：`0` 为完成且未达到设定阈值；`1` 为命中阈值；`2` 为输入或执行错误。`0` 不是安全承诺。

## 检测范围

- `SKILL.md` 常见 frontmatter 的 `name` / `description` 缺失。
- 远程内容直接交给 Shell、潜在破坏性命令、提权与权限绕过选项。
- 上层指令覆盖、隐瞒操作等文本线索。
- 文字中的外部 URL 域名；显式允许清单之外的域名需要复核。
- 常见明文凭据和令牌格式；证据按已知规则脱敏。
- 常见环境变量引用、命令名称、未固定精确版本的 npx 包。
- 常见 MCP JSON 中的命令、参数及环境变量名称。

支持 `.md .json .yaml .yml .toml .txt .sh .py .js .ts`，UTF-8 文本。上限：100 个文件，每文件 1 MiB，总计 5 MiB。CLI 跳过符号链接、二进制、`.git`、`node_modules`、`dist` 和虚拟环境。

## 局限

静态匹配可能误报或漏报，不能识别全部动态拼接、隐蔽行为、恶意依赖或真实权限。文档链接不代表实际外联，反面示例也可能命中。frontmatter 不是完整 YAML 校验，当前不检查所有官方规范字段、引用文件存在性或跨客户端兼容性。

导出不含完整原始输入，但包含文件名、指纹、部分证据与用户填写的说明。自动脱敏不覆盖所有敏感信息；分享前请自行复核。工具不会自动批准上线。

## 项目结构

```text
dist/           零依赖静态网站和浏览器分析引擎
cli.mjs         本地命令行入口
server.mjs      仅监听本机的预览服务器
tests/          分析引擎与 CLI 行为测试
docs/           趋势证据、客户验证与交付计划
```

部署静态站点时发布 `dist/` 即可。公开入口使用 GitHub Pages 的 `gh-pages` 分支；更新网站后可用 `git subtree split --prefix=dist --branch gh-pages` 并推送该分支。本站托管包只包含该目录与必要的托管清单，不包括研究笔记、原始用户资料或本机环境配置。
